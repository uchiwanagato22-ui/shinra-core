HOW TO TEST v27
================================================================================

1. CHARACTER CREATION
   - Start app → Character Creator
   - Change skin color, hair style, eyes, outfit
   - Verify: All combinations work, rendering is smooth

2. ANIMATION LIBRARY
   - Character Creator → Library
   - Select "Movement" tab
   - Click "Walk Forward"
   - Verify: Animation loads and previews

3. TIMELINE ANIMATION
   - Click "Animate" tab
   - Play animation (Press Play button)

4. IMAGE UPLOAD

   - Select a PNG image
   - Verify: Image appears and segments into parts

5. EXPORT (GIF)
   - Export → Select "GIF" format

   - Verify: GIF file created, can be played

   - Click Export
   - Verify: MP4 frame sequence created, ready for encoding

7. SAVE/LOAD PROJECT

   - Restart app
   - Load project
   - Verify: All settings preserved

================================================================================
TROUBLESHOOTING
================================================================================

Q: Export button doesn't work?
A: Make sure viewport is visible. Check console for errors.

Q: Animation looks choppy?
A: Increase FPS to 30+. Reduce number of bones if needed.

Q: Image doesn't upload?
A: Check file format (PNG/JPG). Maximum size: 2048x2048.

Q: Out of memory?
A: Export smaller resolution. Close other apps.

Q: MP4 export just creates PNG folder?
A: Expected! Use ffmpeg to convert: ffmpeg -framerate 30 -i frame_%04d.png -c:v libx264 output.mp4
