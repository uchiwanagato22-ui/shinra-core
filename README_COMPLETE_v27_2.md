## 🔧 Technical Details

### Architecture
```
rig.dart                       - Core data model (Bones, Parts, Keyframes)
animation_loader.dart         - JSON → AnimationClip loader
animation_rig_sync.dart       - Perfect sync system (bone interpolation)
pipeline_validator.dart       - E2E validation
video_export.dart             - MP4/GIF/PNG encoding
enhanced_segmentation.dart    - Image decomposition
audio_cue_service.dart        - Audio timeline sync
```

### Animation Format
```json
{
  "id": "walk_forward",
  "duration": 1.2,
  "loop": true,
  "tracks": {
    "leg_left": [
      {"time": 0.0, "x": -10, "y": 100, "rotation": 0, "scale": 1.0},
      {"time": 0.3, "x": -15, "y": 95, "rotation": -30, "scale": 1.0},
      ...
    ],
    "torso": [...],
    ...
  }
}
```

### Sync System
- Animations are bone-agnostic (stored as bone_id → keyframes)
- Character appearance is visual-only
- Both use same bone IDs → sync never breaks
- Works with: procedural, uploaded image, drawn, hybrid
