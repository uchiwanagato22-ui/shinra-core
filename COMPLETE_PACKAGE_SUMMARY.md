## 💡 Pro Tips

### For Best Quality
1. Use desktop (faster export, better performance)
2. Export at 1080p or higher
3. Use 30 FPS (smoother than 24)
4. Create more keyframes (smoother motion)
5. Test validation before export

### For Fastest Export
1. Use mobile resolution (720p)
2. Use 24 FPS (not 30)
3. Use GIF instead of MP4
4. Split long animations into multiple files
5. Use fewer characters (1-2 instead of 5)

### For Best Animation Quality
1. Use 60+ keyframes per bone
2. Use easing curves (v28)
3. Preview with onion skin (v28)
4. Test sync validation
5. Match animation to character (slow walk for heavy character)

### For Multi-Character Scenes
1. Start with 2 characters (easier to manage)
2. Synchronize their animations (use timeline markers)
3. Test sync before export
4. Export at 24 FPS if performance drops
5. Use desktop for best results
